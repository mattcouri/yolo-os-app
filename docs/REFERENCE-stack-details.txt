Overview

This is a single-page React application backed by Supabase (auth, database, storage, edge functions). There is no custom Node/Express server — the frontend talks directly to Supabase.

Environment & Deployment



Required environment variables

VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key

If these are missing, the client falls back to local Supabase defaults (http://127.0.0.1:54321).

Quick start

# Prerequisites: Node.js 18+
npm install
npm run dev      # http://localhost:3000
npm run build    # production build → dist/
npm run preview  # preview on :4173



Supabase setup

supabase link --project-ref <your-project-ref>
supabase db push
